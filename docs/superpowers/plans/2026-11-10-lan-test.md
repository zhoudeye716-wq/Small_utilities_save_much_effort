# 局域网联机测试实施计划

> 实施时使用 Superpowers 的执行计划流程，按任务检查并记录结果。

**目标**　交付独立测试板块，使用户在多台安卓、iPhone 和 iPad 上验证局域网发现和通信。

**结构**　`pages/lan-test/` 管理交互和页面生命周期。`utils/lan-test/` 分离报文编码、UDP 房间、统计与日志存储。房主负责房间成员，测试以每个成员及每个方向为单位进行。

**技术**　原生微信小程序、UDP、微信本机存储与复制接口、Node.js 内置测试运行器。

**设计依据**　[局域网联机测试设计](../specs/2026-11-10-lan-test-design.md)

## 约束与检查重点

- 首页新增入口并注册新页面。保留六个已有工具及其本机数据，使用独立存储键。
- 报文完整编码后严格小于 4096 字节。UDP 测试按测试 ID 和序号去重，原始结果和重发结果分别统计。
- 搜索依赖广播。手动加入独立走单播握手，搜索失败仍可使用。任何设备或系统上的可用性以真机结果为准。
- 最近一次结果和有限日志保存在本机，一键复制由用户触发，复制内容说明包含哪些网络和设备信息。
- 房主退出、切后台、设备切网、两个测试重叠、同端口冲突和存储失败都要显示可辨认状态。房间不依赖云服务。

## 一、协议与统计

**文件**　`utils/lan-test/protocol.js`、`utils/lan-test/metrics.js`、`tests/lan-test-protocol.test.js`、`tests/lan-test-metrics.test.js`

- [ ] 定义协议版本、房间 ID、成员临时 ID、请求 ID、测试 ID、序号与报文类型。编解码验证字段、UTF‑8 实际长度和 4096 字节上限，忽略损坏或版本不兼容的数据。
- [ ] 用发送端同一时钟记录每次往返时长及超时，给出样本量、平均、中位数、95 分位和最大值。零有效样本返回不可计算。
- [ ] 接收端按测试 ID 和序号记录唯一消息、重复和乱序。原始送达率按实际成功接收的唯一序号与实际尝试发送数计算。报告丢失时标记未收到，不推算成功。
- [ ] 吞吐统计有效载荷字节、时长和 KiB/s，注明统计起止与协议开销。先为乱序、重复、缺失、超时、报文超长、多字节文本、测试 ID 不同及没有样本编写回归用例，再实现并运行对应测试。

## 二、房间与收发

**文件**　`utils/lan-test/room.js`、`tests/lan-test-room.test.js`

- [ ] 使用依赖注入的 UDP 适配器实现 `createRoom`、`searchRooms`、`joinRoom`、`leaveRoom` 和 `close`。房主固定测试端口，搜索者用独立端口广播，房主向搜索请求来源回复。列表按房间 ID 去重并过期。
- [ ] 手动 IP 和端口使用单播加入握手。按请求 ID 幂等处理重复加入。房主维护成员在线状态，成员收到确认后才进入房间。
- [ ] 在模拟 socket 中覆盖无法绑定、广播失败、未收到回应、重复回应、多个房间、超时、房主离线和重新加入。断线不伪装成成功，不推断错误根因。

## 三、测试执行与日志

**文件**　`utils/lan-test/runner.js`、`utils/lan-test/log.js`、`tests/lan-test-runner.test.js`

- [ ] 选择成员和方向后执行单条消息、30 次延迟、100 条连续消息与限时吞吐。每轮在开始、进行中、完成、中断和失败间转换。丢包与最终报告分别设置超时，避免界面无限等待。
- [ ] 主机可请求成员报告，成员离线或报告未收到时保留本机部分结果。切后台、退出房间、重建房间和切换网络时停止计时与 socket，并显示当前轮次中断。
- [ ] 使用独立存储键保存最近一次报告和有上限的日志，保留关键错误、汇总与截断标识。存储失败时当前页面仍保留结果并提示。复制时包含设备版本、房间 ID、地址端口、测试 ID、参数、结果与错误，复制前明示。
- [ ] 用注入时钟和模拟 UDP 覆盖无回复、迟到回复、重复回复、测试中离线、日志截断与存储失败。

## 四、独立页面与设备验收

**文件**　`pages/lan-test/index.js`、`pages/lan-test/index.wxml`、`pages/lan-test/index.wxss`、`pages/lan-test/index.json`，以及 `app.json` 和 `pages/home/index.*` 的新增入口

- [ ] 在首页添加「局域网联机测试」，实现建房、搜索、手动加入、成员列表、测试控制、进度、报告和日志。所有信息与错误可在页面看到，并提供复制结果。
- [ ] 运行项目相关自动用例，通过开发者工具确认入口、布局、房间状态与错误显示。模拟器仅用于页面及逻辑调试。
- [ ] 给用户提供真机测试步骤，轮换安卓、iPhone/iPad 为房主，分别在共同 Wi‑Fi 和可用热点下验证。收集双方报告，特别记录 iOS 广播发现、手动加入、切后台及消息时延和丢包。
