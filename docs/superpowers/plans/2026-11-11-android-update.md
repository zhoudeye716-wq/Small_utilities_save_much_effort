# Android 更新实现计划

- 公开发布仓库 `bigpoint/total-release` 保存版本说明及 APK；源码仓库保持私有。Release 标签使用 `v主.次.修订`，每版包含一个 APK。
- App 冷启动时通过多端 API 读取 Android 原生版本，检查公开 Release；非 Android 多端环境不请求。取消后本次进程不再提示，后台返回不重复检查。
- 首页弹窗展示当前版本、新版本和更新说明；确认后显示下载进度，调用微信多端 Android 安装 API，失败时展示明确原因并允许重试。
- 版本解析、平台隔离、错误和下载进度使用自动测试；APK 构建及实际安装由用户在真机上验证。
