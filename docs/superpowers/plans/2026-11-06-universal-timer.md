# 万能倒计时实施计划

**目标：** 在现有微信小程序中增加桌游、对战和多项泡泡计时，提供已确认的十种风格。

**设计依据：** 本对话确认的三个模式、泡泡计时网页预览及十种风格，最后四种重做和水墨重构的预览。

**结构：** 独立页面负责模式和设置、用户交互、生命周期和平台接口；独立计时模型以系统时间计算剩余时间；画布负责泡泡物理和风格绘制。设置及多项计时保存本机，后台不承诺实时提醒。

**约束：** 保留未提交改动；不接服务器；不自动发布；前台持续提醒，离开后回到小程序时根据时间补算；页面保持常亮；默认无翻转；所有风格同时应用页面、控制与提醒。
