# 临时桌牌实施计划

**目标：** 在现有微信小程序中加入离线可用、可手动保存的临时桌牌。

**实现：** 首页入口进入本机桌牌列表；横屏展示页负责实时编辑、测量、滚动和手势。单独的本地存储模块保存记录，不依赖网络或自定义字体。

## 任务

- [x] 接入首页入口、页面路由和本机记录读取/写入/删除，读取异常不覆盖已有数据。
- [x] 实现横屏文字展示、多行测量、自动跑马灯和双指缩放；进入页面请求常亮并在离开时恢复。
- [x] 实现固定色、整体渐变和彩虹流动，文字与背景自定义颜色，实时设置和滚动速度调整。
- [x] 实现手动保存、自定义名称、删除确认及未保存内容返回提醒。
- [x] 更新 README，检查 JavaScript 语法、配置及变更格式，并检查微信开发者工具可用时的页面编译结果。

## 注意事项

- 使用系统粗黑体，不分发授权不明字体；不同设备的字形可能有差异。
- 展示页默认横屏，可切换为跟随设备旋转；具体方向和系统返回行为受微信及设备影响，系统手势退出可能无法拦截。
- 文字以真实测量宽度判断是否滚动；设置面板覆盖画面，不改变判断区域。
- 本地记录操作失败时保留当前内容并提示，不清空原有数据。
