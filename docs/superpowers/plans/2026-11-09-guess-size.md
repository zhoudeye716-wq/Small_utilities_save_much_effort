# 猜大小实施计划

> 实施时按顺序使用 Superpowers 的执行计划流程。用复选框记录进度。

**目标**　把已确认的 C「爆破舱」做成可从小程序首页打开的本机横屏游戏。

**结构**　用纯 JavaScript 模块处理抽数、边界和存档校验。一个横屏页面管理选择、设置、猜数和结果，避免进出设置时切换屏幕方向。页面只用当前边界和输入来渲染，爆雷时才把答案交给结果视图。

**技术**　沿用仓库的原生微信小程序结构、CommonJS 和 Node.js 内置测试运行器。

**设计依据**　[猜大小设计方案](../specs/2026-11-09-guess-size-design.md)

## 实施约束

- 同一台手机或 iPad 线下轮流。开局默认 0–100，自定义范围为 0 ≤ 下限 < 上限 ≤ 9999。
- 只保存一局未完成的对局。开始新局成功后才替换旧局，爆雷时清除存档。
- 两端开局均可猜。猜过的边界继续显示并标记为「已排除」。只剩一个数也等玩家提交。
- 沿用已确认的 C 布局。底部一排 0–9 和「确定」，点中央清空。
- 按可猜数字数目调节双拍间隔。猜错加速飞向对应边界，落位高亮并同向回弹。爆雷反馈更强，声音和振动默认开启并可分别关闭。

## 一、猜数规则

**文件**　`utils/guess-size.js`，`tests/guess-size.test.js`

- [x] 定义 `settings` 包含 `lower`、`upper`、`sound`、`vibration`。局面包含 `settings`、`answer`、`left`、`right`、`leftOpen`、`rightOpen`。开局的两个 `Open` 均为 `false`。
- [x] 实现 `validateSettings(settings)`、`startRound(settings, random = Math.random)` 和 `isSavedRound(value)`。抽数包含两个端点。拒绝越界设置、非整数和隐藏答案已被排除的存档。
- [x] 实现 `guessNumber(round, input)`，分别返回 `invalid`、`left`、`right`、`hit` 四种结果。猜错返回新局面，原局面保持可用于飞行动画。实现 `countRemaining(round)` 供心跳计算。
- [x] 验收用例覆盖随机值 0 与接近 1 时分别抽中两端，设置 0–9999 合法，9999–10000 和相等的边界无效。答案 77 时猜 78 更新右界，猜 76 更新左界。两端排除后只剩 77，提交 76 或 78 均无效，提交 77 才命中。用 `node --test tests/guess-size.test.js` 验证这些规则。

## 二、入口和本机续局

**文件**　`app.json`，`pages/home/index.js`，`pages/home/index.wxml`，`pages/guess-size/index.json`，`pages/guess-size/index.js`，`pages/guess-size/index.wxml`，`pages/guess-size/index.wxss`

- [x] 注册 `pages/guess-size/index`，从首页「猜大小」进入。沿用临时桌牌的横屏页面配置，开局、选择存档、对局和结果用同一页面。
- [x] 用一个本机键 `guess-size-current-v1` 存储局面。入页先校验存档，有效时给「继续对局」和「新开一局」，没有有效存档则展示设置。继续恢复原答案和边界，输入框清空。
- [x] 新局创建或有效猜错时先保存新局面，再推进界面。存档写入失败时给出提示并保留旧局面。猜中先清除续局存档，再进入爆雷和结果。页面退出或隐藏时清理待执行的动画回调。
- [x] 验收有存档时打开新局设置再返回，仍能继续旧局。确认新局后重新进入只看到新局。猜错动画中退出，再进入恢复已经提交的边界。爆雷后重新进入直接显示开局设置。

## 三、横屏布局和动效

**文件**　`pages/guess-size/index.js`，`pages/guess-size/index.wxml`，`pages/guess-size/index.wxss`，`assets/guess-size-burst.wav`

- [x] 实现 C 版固定三栏、端点状态、输入框和数字键。支持四位数和点中央清空，空白、越界、已排除值给出提示。手机和 iPad 按可用宽度排布，四位数不挤占按键。
- [x] 等待时按剩余候选数计算双拍间隔，约从 1.8 秒递减到 0.9 秒。提交有效猜测后锁定重复提交，暂停心跳。猜错时让字形先蓄力、再带淡残影加速飞行，直到落位才更新显示边界。被撞侧边框亮一下，整屏同向位移并回弹，随后恢复心跳。
- [x] 猜中时播放更强的画面冲击和答案揭晓。开关独立控制本地爆破音和设备振动，每次爆雷各触发一次。结果页的「再来一局」用本局设置重新随机抽数并恢复初始边界。
- [x] 在模拟器核对左右飞行和落位后的边界，并用页面用例验证连续点「确定」只提交一次。实际声音和振动在真机验收。
