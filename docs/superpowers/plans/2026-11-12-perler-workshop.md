# 拼豆工作台实施计划

**目标：** 在微信小程序与 Android 共享源码中增加本机图片转拼豆、编辑、底板对照与导出。

**约束：** 保留首页现有修改；图片和项目仅保存在本机；用户自行构建 APK；沿用参考项目许可证并标明来源。实际权限和旋转表现必须真机确认。

## 步骤

- [ ] 核对参考项目调色板、算法、许可证及平台相册与画布能力。
- [ ] 用自动化测试覆盖图像网格、配色、项目存储、校准及分块导出的关键规则。
- [ ] 实现本地项目列表、图片导入、自动生成和编辑，保留多份项目与删除本机副本。
- [ ] 实现设备校准、独立比例与位置锁定、双指缩放及滚轮微调。
- [ ] 实现导出预览、选项及正方形分块，处理镜像和坐标。
- [ ] 接入首页，更新许可证和致谢，执行自动测试与双端可行的检查，记录尚需真机验证的部分。

## 高风险检查

- 原图、保存失败或清理失败时不得报告成功或删除用户相册原件。
- 重新生成会覆盖单格编辑时需确认；过时的异步计算不得覆盖新结果。
- 不同屏幕尺寸和旋转不得改变已锁定的每格物理比例。
- 统计、镜像和分块坐标应与实际导出一致。
- 大图的内存、导出及相册 API 应对两个运行环境分别验证。
