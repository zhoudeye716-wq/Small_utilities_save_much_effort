# 麻将新手引导与时间分摊实施计划

**目标：** 为新对局提供可关闭的新手引导，记录本场人员到离场时间，并按台费时间和人员在场时长计算及调整整场台费。

**架构：** 新对局使用 `rulesVersion: 2`，旧对局不改变人数校验；新对局每人 `attendance` 保存多个 `{start, end}` 毫秒时间区间，最初在场者的 `start: null` 表示从费用开始算，`end: null` 表示仍在场。新台费使用 `mode: 'time'` 及 `startAt/endAt`，历史费用保持原有规则。手动分摊保存于对局 `manualFeeShares`（玩家 ID 到整数分），相关台费或人员时间变化时清除。所有已保存清算快照保持原样。

## 任务

- [x] 扩展计算引擎：按台费时段与到离场区间的交集计算时长，按权重精确分配整数分，合计手动调整并保持历史费用兼容；仅新对局强制 3/4 人。
- [x] 建立可复用时间选择器：日期、24 小时滚轮、次日和 3–6 小时快捷时长，供引导和台费页使用。
- [x] 新手引导：本机记住开关、三步骤、全局玩家即时保存、临时占位、前四默认、台费可跳过或忽略不完整输入；完成后才保存新对局。
- [x] 对局页面接入人员面板、入离场和重新到场、时间可调整、每轮 3/4 人控制、时间台费和整场手动分摊；更新 README。
- [x] 检查 JavaScript/JSON、页面绑定、差异格式和代码接口兼容性；模拟器与真机交互尚待检查。

## 边界

- 今天到场和本轮上场是独立状态；离场不删除原有轮次或点数。
- 进入清算页不结束对局；每笔费用全额按其时段计算，不以查看时间裁剪。
- 初始名单不足四人用临时默认名补足，改名后才加入本机全局名单；相同名字不能跨 ID 合并。
- 手动合计使用每人默认台费合计作为其余人员分配权重，取整到分且始终守恒；任一影响分摊的数据变化时重置并提示。
- 留出系统时间、跨午夜、无重叠时长、时间误填、记录存取失败的处理；无台费时不要求时间，但到离场事件仍记录。
