# 猜大小设计方案

## 使用场景

朋友围坐共用一台手机或 iPad。大家在线下自行决定顺序，轮到谁就由谁输入数字。小程序负责保管随机答案、更新边界和显示爆雷结果。

## 布局选择

| 草图 | 特点 |
| --- | --- |
| A · 街机大字 | 左右边界字号更大，便于围坐时扫读。 |
| B · 纸牌桌面 | 一条线连接左右边界，输入卡片最突出。 |
| **C · 爆破舱（已选）** | 左右用固定仪表显示边界，中央是爆破面板，右下角的确定键突出。 |

对局页横屏。左侧显示下界，右侧显示上界，每边标明「可猜」或「已排除」。中央显示本次输入，点中央框清空。底部一排放数字键 0–9，最右侧是「确定」。手机和 iPad 使用同一布局，按可用宽度调整区域和按键尺寸。

## 开局和续局

1. 从小程序首页进入「猜大小」。如果有未结束的一局，先显示「继续对局」和「新开一局」。没有存档时直接显示开局设置。
2. 设置初始下限和上限，默认是 0 和 100。范围使用非负整数，满足 0 ≤ 下限 < 上限 ≤ 9999。开局两端均可猜，单次最多输入四位数字。声音和振动分别设置，默认都开启。
3. 点开始时，在初始范围内等概率随机抽一个整数，包含两个端点。整个对局使用同一个答案，直到猜中才揭晓。
4. 点「新开一局」进入设置后，仍可退出并继续旧局。按下「开始新局」时才替换原存档。

## 猜数规则

- 用底部数字键输入，点「确定」提交。空白、超出范围或已排除的边界给出简短提示，不推进对局。
- 猜的数小于答案，就把该数设为显示下界，并标为已排除。猜的数大于答案，则更新显示上界。只改变这一侧。有效提交后清空输入。
- 例如开局显示 0–100，猜 78 且答案更小，显示变为 0–78。此时 0 还可以猜，78 只作为边界显示。
- 如果显示 76–78，两个边界都已排除，只剩 77，也等下一位亲手提交 77 后才爆雷。

## 对局动效

- **等待输入**：整个爆破舱有轻微的双拍心跳。剩余可猜数字越少，双拍之间的间隔越短，抖动幅度保持轻微，范围和按键依然容易看清。预览从开局约 1.8 秒一组逐步加快到只剩一个数字时约 0.9 秒一组，具体节奏以实际观感为准。
- **猜错**：按下「确定」后，暂时停下心跳。中央数字先向反方向退一点蓄力，再加速冲向要更新的一边。高速阶段带一层与数字同高的淡字形残影，接触边界前淡出。猜小撞左界，猜大撞右界。碰撞瞬间替换原边界、标记为已排除，对应边框亮一下，整个画面沿碰撞方向被推出并回弹。落位反馈由边框和画面回弹表现，不加圆环。接着以新的范围恢复心跳。
- **猜中**：中央数字留在爆破面板内，直接触发全屏爆破和答案揭晓。爆破的力度明显强于猜错时的落位反馈。

## 爆雷和重开

爆破用短促的画面震动、面板炸开和答案大字揭晓。爆破音与设备振动遵循开局开关。动画结束后停留在结果画面。

点「再来一局」沿用本局的初始范围和开关，重新独立抽取答案，并恢复两端可猜。

## 本机保存

- 只保存当前一局未结束的对局，记录初始设置、隐藏答案、当前上下界和两端是否可猜。每次有效提交后更新存档。
- 继续时恢复原答案和边界，从空输入框开始。中途退出时可以再次继续。
- 猜中后清除这局的续局记录。结果页仍可用本局设置立即重开。
